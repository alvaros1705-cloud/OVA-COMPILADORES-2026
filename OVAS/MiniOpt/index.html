        Resumen de reglas aplicadas

        Evidencia de equivalencia semántica

        1. Plegado de constantes

        Constant Folding

        Evalúa en tiempo de compilación operaciones cuyos operandos son constantes conocidas. Protege la división y módulo por cero para no alterar excepciones.

        t1 = 5 + 3   →   t1 = 8
        2. Propagación de constantes

        Constant Propagation

        Sustituye usos de variables cuyo valor constante está garantizado dentro del bloque básico. Se reinicia en etiquetas y al reasignar para preservar ciclos y bifurcaciones.

        t1 = 8
t2 = t1 * 2  →  t2 = 8 * 2
        3. Simplificación algebraica

        Algebraic Identities

        Aplica identidades exactas como x + 0 = x, x - 0 = x, x * 1 = x, x / 1 = x, x * 0 = 0 y x - x = 0. Evita 0 / x y x / x si x puede ser cero.

        t3 = t2 + 0  →  t3 = t2
        4. Temporales redundantes

        Copy & Temp Elimination

        Elimina copias intermedias innecesarias (t1 = a; x = t1), auto-asignaciones (x = x) y fusiona temporales de uso único inmediato en la variable destino.

        t1 = a + b
x = t1       →  x = a + b
        5. Código muerto

        Dead Code Elimination

        Retira temporales sin uso, asignaciones sobrescritas antes de leerse y código inalcanzable tras un goto/return. Conserva siempre variables de salida y efectos secundarios.

        x = 10
x = 20       →  x = 20
        Restricción esencial

        Seguridad Semántica Primero

        Nunca se eliminan instrucciones con efectos secundarios (print, read, call, param, return) ni se optimiza a través de saltos sin garantía. Si una regla no es 100% segura, la instrucción se conserva.

        t1 = call leer, 0  (conservada)
